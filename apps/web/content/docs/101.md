# Quickstart

Five minutes, four commands. At the end Sovkora answers you on your own machine, and nothing left it.

## Before you start

You need git, Java 21, Node.js 22+, Python 3.11+, Docker and Ollama. `npx sovkora doctor` checks them for you.

## 1. Install

```bash
npx sovkora install
```

It checks your tools, clones the platform into `./orazaka` and writes the configuration. Then build once:

```bash
cd sovkora && ./mvnw install && pnpm install
```

## 2. Start

```bash
npx sovkora start    # PostgreSQL, Redis, RabbitMQ and the local AI engines
npx sovkora dev      # the services and the web app
```

Open `http://localhost:3000`.

## 3. Meet Eric

```bash
npx sovkora demo seed
```

This creates Eric, a demo persona with a plan, packs and Studios. Run it again at any time: it is replayable. Sign in as Eric and ask a question in the chat.

## 4. Ask and run from the terminal

```bash
npx sovkora chat "In two sentences: what can you do?"
npx sovkora studio list
npx sovkora studio run <installation> --inputs key=value
```

A Studio is a ready-made workflow with its own form. The [Studio guide](STUDIO_GUIDE.md) shows one from start to finish.

## If something fails

Run `npx sovkora doctor`. It names what is missing and how to fix it. `npx sovkora onboard` replays the whole check on a fresh clone.
